# Anatomy Education Assistant (RAG)

A Streamlit-based educational assistant that answers questions using a curated anatomy resource collection. It combines retrieval from a local ChromaDB vector database with Google Gemini text generation and can return a related anatomy image when a relevant match is found.

## Features
- Simple Streamlit question-and-answer interface.
- Retrieves relevant text from a persistent ChromaDB collection.
- Searches a separate image collection and displays a matching local image.
- Uses Gemini to generate a title and a natural-language response grounded in retrieved results.

## Architecture
- `st_app.py` — Streamlit interface, retrieval functions and response generation.
- `image_filenames.csv` — image names/descriptions used to connect retrieved image descriptions to local files.
- `images/` — expected directory for image assets (ensure it exists locally).
- `collection/` — expected persistent ChromaDB data with `my_collection` and `images` collections.
- `imageExtract.py`, `img_fetch.py`, `my_script.py` — supporting extraction/ingestion utilities.
- `requirements.txt` — Python dependencies.
- `anatomy_vol_3_edited_final.pdf` — source reference material.

## Setup
Use Python 3.10+ where supported by the pinned dependencies.
```bash
git clone https://github.com/Saikabilane/RAG.git
cd RAG
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

Set a Gemini API key through an environment variable and update the app to read it from the environment rather than hard-coding credentials. Never commit API keys to Git. If a real key has ever been committed, revoke/rotate it before continuing.

The app expects the ChromaDB collections and image metadata to be prepared before launch. Review the helper scripts and their paths to understand or recreate the ingestion process. Then run:
```bash
streamlit run st_app.py
```

## Limitations
Answers are generated by an AI model and may be incomplete or incorrect. Treat this as a study aid, verify important anatomy information against trusted sources, and do not use it for diagnosis or treatment decisions.
